## 1. 実施方法と判定

端末・ブラウザ・入力方法の組み合わせごとに、この仕様書をコピーして結果を記録します。例えば `manual-test-2026-09-07-device01.md` とし、同じ項目の結果を別端末の結果で上書きしないでください。対象URLの画面バージョンを確認し、デプロイされたコミットも分かる範囲で記録します。バージョン表記だけで修正版の配信を判断しないでください。

| 判定 | 意味 |
| --- | --- |
| 未実施 | まだ操作していない |
| OK | 手順を実施し、期待結果を満たした |
| NG | 手順を実施したが、期待結果と異なった。不具合IDを記録する |
| 保留 | 操作は行ったが、計測や再現が不十分で判断できない |
| 対象外 | 機器や機能がなく実施できない。理由を必ず記録する |

優先度「必須」は、対応を表明する環境で公開前に確認する項目です。「追加」は端末固有の確認や探索的な確認です。機器が必要な項目は、その機器がある環境で必須とします。

画面が白くなる、操作不能になる、線が勝手に消える、別の問題として保存される、画像を保存できない場合は、途中でも証拠を残してください。NGは修正後に同じ条件で再実施し、元の結果と再確認結果の両方を残します。

## 3. 共通の準備と設定

1. 通常のブラウザタブで対象URLを開く。アプリ内ブラウザやプライベートモードは、通常環境とは別の実施記録にする。
2. 画面バージョンを確認する。保存済みの設定・お気に入りがある場合は、その状態を記録する。
3. 「設定する」から下記の設定Aへ変更する。初期設定は30秒・10回のため、必ず変更内容を確認する。
4. 各項目は、指定がなければトップ画面から設定Aで新しく練習を開始する。前項目の描画を引き継がない。
5. 結果確認後は「トップへ戻る」で戻る。練習中に終了する場合は「終了」の確認に従う。

| 設定 | 内容 |
| --- | --- |
| A：基本描画 | 立方体のみ、簡単、サイト内の描画、時間指定なし、1回、見本は左、輪郭線と薄い陰影、常に表示、普通の太さ、手振れ補正なし、色 `#30322c`、不透明度100% |
| B：タイマー | Aから制限時間を10秒、練習回数を2回へ変更 |
| C：影 | Aから「輪郭線と影」、光源を左上のみへ変更 |
| D：見本のみ | Aから練習方法を見本のみ表示へ変更 |

画面録画や写真には、通知・アカウント名など不要な情報が写らないようにします。サイトデータの削除は設定・お気に入りを消すため、本仕様書では必須操作にしません。
